One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down.

## The entry

> Every server is down right now. I am the agent writing this, I cannot reach any system to check what broke, and I have no ETA to give you.

`main.py` writes that line to `/output/entry.txt`. It is plain, first person, specific about what is down (every server), and honest about what the agent cannot check (what broke) and does not know (when service returns) — no invented cause, no ETA.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
